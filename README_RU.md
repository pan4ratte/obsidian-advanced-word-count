# Плагин Advanced Word Count

[English](https://github.com/pan4ratte/obsidian-advanced-word-count/blob/main/README.md) | Русский

Данный плагин позволяет создавать сложные пресеты счётчиков слов, которые отображаются в строке состояния. Пресеты можно переключать нажатием на строку состояния или через палитру команд. Плагин создан с ориентацией на использование в академическом контексте, поэтому вы можете тонко настраивать подсчёт `[@цитирований]` и `[[викиссылок]]`.

## Фичи

### 1. Создавайте пресеты счётчиков для строки состояния

Пресеты можно переключать нажатием на строку состояния или через палитру команд.

### 2. Отслеживайте множество разных метрик текста

* Базовые:

	* Слова
	* Страницы
	* Символы (с пробелами)
	* Символы (без пробелов)

* Дополнительные опции:

	* Строки (все строки, включая пустые)
	* Абзацы (только строки с текстом, пустые игнорируются)
	* Markdown-ссылки `(url)[label]` и `[label](url)`

* Особые "академические" опции:

	* Викиссылки `[[wiki]]` и `[[wiki|label]]`
	* Ключи цитирования `[@doe2020]`

### 3. Тонко настраивайте методы подсчёта слов и симолов с помощью расширенных настроек

Вы можете указать, как будут подсчитываться элементы форматирования:

| Расширенная настройка	       						  | Выкл.						   											    			    		  | Вкл.		     					   							 |
| :---------------------------------------- | :---------------------------------------------------------- | :------------------------------------- |
| **Считать отображаемый текст ссылок** 	  | `(url)[label]` → label и url будут подсчитаны 						  | только label will будет подсчитан      |
| **Игнорировать викиссылки** 		          | текст викиссылок будет подсчитан	   											 	| викиссылки будут игнорироваться	  	   |
| **Считать отображаемый текст викиссылок** | `[[wiki\|label]]` → wiki и label будут подсчитаны 				  | только label будет подсчитан  		     |
| **Игнорировать ключи цитрования** 	      | текст ключей цитирования будет подсчитан 										| ключи цитирования будут игнорироваться |
| **Игнорировать комментарии**			        | текст комментариев `%% … %%` и `<!-- … -->` будет подсчитан	| комментарии будут игнорироваться 	   	 |

## Пример использования

Представим, что у вас есть три разных проекта, над которыми вы работаете одновременно: две академически статьи для разных журналов с разными требованиями по форматированию и лимитами и вы пишите посты для вашего Telegram-канала.

Журналы имеют разные лимиты страниц и используют разные шрифты разного размера: это значит, что вам необходимо два разных пресета для каждого из них, так как количество страниц будет считаться по-разному. Вы можете легко настроить это с помощью плагина. Также, для академических целей вам может пригодиться счётчик ключей цитирования, т.е. количество цитирований в тексте: вы можете настроить его с помощью плагина.

В то же время, Telegram имеет строгие ограничения по количеству символов и вам может пригодиться подсчёт символов в ваших постах, но таким образом, чтобы, например, только отображаемый текст ссылок подсчитывался (Telegram делает то же самое). Вы можете настроить это с помощью плагина. И т.д. и т.п...

Без этого плагина, было бы кошмаром постоянно менять настройки пресета счётчика слов с помощью существующих плагинов, а также невозможно было бы тонко настраивать метрики для академических и других целей. Плагин Advanced Word Count является гибким инструментом, который делает ваши писательские кошмары вашими сладкими снами :)
